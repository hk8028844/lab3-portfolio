# Personal Portfolio

Personal portfolio website for CS344: Web Engineering (Lab 3, Fall 2026).

**Muhammad Hamza Khalid** | CMS ID: 501587 | Section: B

Built with plain HTML, Bootstrap 5.3.3 (CSS only, no JavaScript), and one custom stylesheet. Bootstrap is stored locally in `css/bootstrap.min.css`, so the site works offline and on GitHub Pages without depending on a CDN.

## Pages

| Page | What it has |
| --- | --- |
| `index.html` | Home page with intro and quick links |
| `hobbies.html` | My hobbies and interests |
| `gallery.html` | Image gallery (5 images) |
| `skills.html` | Core skills |
| `contact.html` | Email and phone |
